# Roadmap

## 0.3 (Implemented, Unreleased)

- SQLite driver
- Batched emit API
- Optional probabilistic cleanup
- Integration test fixtures for each framework adapter
- Admin diagnostics UI
- Documented pluggable event stores
- Metrics hooks and callable OpenTelemetry bridge

- Independent channel cursors and retention-gap resync
- Async token refresh for cross-tab subscription unions

- Database integration tests, Playwright multi-tab coverage, and CI

## 0.1

- Vanilla PHP core and browser SDK
- MySQL, MariaDB, and PostgreSQL schemas
- Laravel, WordPress, Symfony, and CodeIgniter adapters
- Signed channel grants and database rate limiting
