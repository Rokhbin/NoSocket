# Contributing

Thanks for helping make realtime UI practical on ordinary hosting.

1. Open an issue before broad architectural changes.
2. Keep the core dependency-light and compatible with PHP 8.1.
3. Add focused tests for behavior changes.
4. Run `composer test`, `npm test`, and PHP lint before opening a pull request.
5. Keep documentation honest about latency and hosting limits.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) and report security issues through [SECURITY.md](SECURITY.md).
